# tinyMind 儿童小游戏合集 — 设计文档

> 日期：2026-06-17
> 状态：已确认，待制定实现计划

## 1. 项目概述

为 4 岁孩子打造的网页小游戏合集，家长可陪伴共玩。第一版收录 2 个游戏：

- **舒尔特方格**（Schulte Grid）— 专注力训练
- **记忆对对碰**（Memory Match）— 双人比赛，记忆配对

部署到 GitHub Pages，手机/Pad 浏览器打开即玩，无需安装。

## 2. 目标用户

- 主要用户：4 岁儿童（需要大按钮、明亮色彩、语音/音效引导、无挫败感设计）
- 次要用户：家长（陪伴游戏、比赛模式中的对手方）

## 3. 技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 框架 | React 18 + TypeScript | 组件化适合「游戏合集」结构，每个游戏独立 |
| 构建 | Vite | 秒级热更新，`base` 配置适配 GitHub Pages 子路径部署 |
| 动画 | Framer Motion | 声明式动画，翻转/弹跳/庆祝粒子/页面转场，spring 效果适合儿童 Q 弹触感 |
| 样式 | Tailwind CSS | 响应式，手机/Pad 自适应开箱即用 |
| 路由 | React Router | 首页 ↔ 各游戏页面路由 |
| 国际化 | react-i18next | 中英双语切换 |
| 测试 | Vitest + Testing Library | 组件/逻辑测试 |

## 4. 项目结构

```
tinyMind/
├── src/
│   ├── app/              # 应用入口、路由、布局壳
│   ├── components/       # 通用 UI（Card、Button、Confetti、AudioButton）
│   ├── games/            # 每个游戏一个文件夹，互不依赖
│   │   ├── schulte/      # 舒尔特方格
│   │   └── memory-match/ # 记忆对对碰
│   ├── i18n/             # 中英双语文案
│   ├── lib/              # 工具：音频播放、localStorage 设置
│   └── hooks/            # 复用逻辑（计时器、随机打乱等）
├── public/
│   └── sounds/           # 音效文件
├── .github/
│   └── workflows/        # GitHub Pages 自动部署
└── docs/
```

**新增游戏的成本**：在 `games/` 下加一个文件夹 + 在路由/首页注册一个入口，其余不动。

## 5. 通用 UI/UX 设计

### 5.1 视觉风格
- 卡通可爱风：圆角卡片、明亮饱和色调、大号字体
- 图标素材：使用 Emoji（零素材依赖，色彩鲜明，儿童认知友好）

### 5.2 国际化
- 中英双语切换，全局可用（顶部语言切换按钮）
- 舒尔特方格数字显示阿拉伯数字，中英双语仅影响 UI 提示文案
- 记忆对对碰配对成功时显示图案对应的中英文名称（如 🐶 狗/Dog）

### 5.3 音效反馈
- 答对：轻快音效
- 答错：柔和提示音（不否定、不刺耳）
- 完成：庆祝音效（如掌声、欢呼）
- 音效开关：全局可静音

### 5.4 动画反馈（Framer Motion）
- 卡片翻转：3D `rotateY`，spring 弹簧效果
- 答对：弹跳 + 高亮变绿
- 答错：轻微震动
- 完成：全屏撒花粒子（Confetti）

### 5.5 响应式适配
- 手机端：纵向布局，大触摸目标（最小 60px）
- Pad 端：横向布局，更大卡片
- 使用 Tailwind 断点（sm/md/lg）

## 6. 游戏详细设计

### 6.1 舒尔特方格（Schulte Grid）

**核心玩法**：方格内随机排列数字，孩子按指定顺序点击完所有数字。

**三种模式**：

| 模式 | 目标序列 | 说明 |
|------|----------|------|
| 正序 | 1→2→3→...→N | 经典模式 |
| 倒序 | N→N-1→...→1 | 逆向训练 |
| 乱序 | 随机打乱（如 1,3,6,10...） | 系统在顶部提示「下一个找 X」，不按连续顺序，考验反应力 |

**难度分级**：
- 3×3（数字 1-9）
- 4×4（数字 1-16）
- 5×5（数字 1-25）

**交互流程**：
1. 选择模式 + 难度 → 开始
2. 方格内随机排列数字
3. 正序/倒序模式：孩子按顺序点击；乱序模式：顶部提示「下一个找 X」，找到后提示下一个
4. 点击第一个格子开始计时
5. 点对 → 格子高亮变绿 + 轻快音效
6. 点错 → 轻微震动 + 柔和提示音（不否定）
7. 完成全部 → 停止计时 → 全屏撒花 + 庆祝音效 + 显示用时

**记录**：用 localStorage 保存最佳用时（可选，鼓励「比上次更快」）

### 6.2 记忆对对碰（Memory Match）

**核心玩法**：卡片背面朝上，两名玩家轮流翻开找配对，找到所有配对即结束。

**双人比赛机制**：

| 机制 | 说明 |
|------|------|
| 玩家 | 2 人轮流（家长 vs 孩子），开始时输入/选择双方昵称 |
| 回合 | 轮流翻两张牌；配对成功 → 得 1 分 + 继续翻；失败 → 换对方 |
| 结束 | 全部配对完成，比分分胜负，平局也有庆祝 |
| 适童年 | 不限时、不扣分、只加分，避免挫败感 |

**难度分级**（卡片数量 = 配对数 × 2）：
- 简单：4 张（2 对）
- 中等：8 张（4 对）
- 困难：12 张（6 对）

**卡面素材**：卡通 Emoji（动物、水果、交通等）

**交互流程**：
1. 选择难度 + 输入双方昵称 → 开始
2. 当前玩家翻第一张牌（3D 翻转动画）
3. 同一玩家翻第二张牌
4. 配对成功 → 两张卡片弹跳 + 撒花 + 音效 + 显示图案中英文名 → 得分 + 继续翻
5. 配对失败 → 短暂停留（约 1 秒，让孩子记住位置）→ 卡片翻回 → 换对方
6. 全部配对完成 → 统计双方得分 + 用时 + 全屏庆祝 + 胜方高亮

**界面元素**：
- 顶部：双方昵称 + 实时比分 + 当前轮到谁（高亮提示）
- 中央：卡片网格
- 底部：重新开始 / 返回首页

## 7. 部署方案

- GitHub Actions：push 到 main → 自动 `vite build` → 发布到 GitHub Pages
- Vite `base` 配置为仓库名（`/tinyMind/`）适配子路径
- 纯静态部署，无需后端

## 8. 范围边界（YAGNI）

第一版**不做**：
- 用户账号 / 登录
- 排行榜 / 云端成绩同步（仅 localStorage 本地记录）
- 成就系统
- 3 个以上的游戏（先做这 2 个，验证后再加）
- 自定义卡面上传
- 后端服务
